# Agent instructions

Equivalent, standalone templates: [English](AGENTS.project.md) / [Japanese](AGENTS.project.ja.md). Choose one.

## Installation

- Install the chosen template as `<repository>/AGENTS.md`. Use a global `AGENTS.md` in the Codex home directory only when the policy should apply across repositories.
- Merge existing instructions and preserve local additions. Avoid duplicating the policy across scopes; keep project-specific commands and conventions in repository instructions.
- These source filenames are not standard automatic instruction filenames. Editing them does not update installed copies, and this README need not be deployed.

See the [official AGENTS.md documentation](https://learn.chatgpt.com/docs/agent-configuration/agents-md) for discovery, overrides, and loading limits.

## Updates

Keep both language versions equivalent. Review the diff, preserve local additions and a rollback reference, and update installed copies separately. Check instruction loading when changing installation or scope; report checks that could not be performed.
