# agent の指示

単独で使える同じ意味のテンプレート：[英語版](AGENTS.project.md) / [日本語版](AGENTS.project.ja.md)。どちらか一方を選びます。この README はセットアップのガイドで、配置は不要です。

## 配置

- 選んだ版を `<repository>/AGENTS.md` として配置します。配布元の名前は標準の自動読み込み対象ではありません。方針全体をプロジェクト横断で適用する場合だけ、Codex home のグローバル `AGENTS.md` を使います。両範囲への重複配置を避け、局所的なコマンドや慣例はリポジトリ指示で補足できます。
- 既存の指示を統合し、局所的な追加と無関係な作業を保ちます。適用ファイルが有効な読み込み上限に収まり、必須の独立レビューが許可され利用できることを確認します。レビュー条件、gate、記録はテンプレートに定義しています。
- 配布元の編集では配置済みの指示は更新されません。このリポジトリ外への配置は別の操作です。

探索と設定は[公式 AGENTS.md ドキュメント](https://learn.chatgpt.com/docs/agent-configuration/agents-md)を参照します。override と設定済み fallback 名を確認します。同じディレクトリの override が配置したファイルを置き換える場合があります。

## 移行と更新

1. 配置済みの版と配布元を比較し、局所的な追加と rollback 用の参照を保ちます。旧 `AGENTS.user.md` と `.agent/agent-execution-policy.md` は日本語版を含めて統合済みで、別ポリシーは不要です。
2. 対象の `AGENTS.md` と不要なポリシー読み取り指示を更新します。旧ファイルは残る指示や利用者が不要とすることを確認してから削除し、無関係な `.agent/` ファイルを保ちます。
3. 配布元の英日を同じ意味に保ち、差分と影響するレビュー、独立性、受入、保留規則を確認します。変更はテンプレートの適用条件と gate に従ってレビューします。
4. 有効な読み込み・探索の証拠を再利用し、設定、範囲、容量、証拠不足に関係するチェックだけを繰り返します。通常の内容更新でセットアップ全体のやり直しは不要です。

初回配置や範囲の移行では、配置先、適用ファイルと設定、読み込み容量を確認します。runtime の探索確認は新しいセッションで行い、利用可能な指示元表示やログで報告を裏付けます。自己申告だけで全文読み込みを確認したとは扱いません。利用できないチェックや不確実性を報告し、配布元の検査を runtime 配置の検証とは扱いません。
