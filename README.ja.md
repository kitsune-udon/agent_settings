# agent の指示

単独で使える同じ意味のテンプレート：[英語版](AGENTS.project.md) / [日本語版](AGENTS.project.ja.md)。どちらか一方を選びます。

## 配置

- 選んだ版を `<repository>/AGENTS.md` として配置します。方針をプロジェクト横断で適用する場合だけ、Codex home のグローバル `AGENTS.md` を使います。
- 既存の指示を統合し、局所的な追加を保ちます。適用範囲をまたぐ方針の重複を避け、プロジェクト固有のコマンドや慣例はリポジトリの指示に置きます。
- 配布元の名前は標準の自動読み込み対象ではありません。配布元を編集しても配置済みのファイルは更新されず、この README の配置も不要です。

探索、override、読み込み上限は[公式 AGENTS.md ドキュメント](https://learn.chatgpt.com/docs/agent-configuration/agents-md)を参照します。

## 更新

英日を同じ意味に保ちます。差分を確認し、局所的な追加と rollback 用の参照を保って、配置済みのファイルを別途更新します。配置や適用範囲を変えた場合は読み込みを確認し、実施できなかった検証を報告します。
